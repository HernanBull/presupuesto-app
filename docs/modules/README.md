# Módulos (Documentación de Arquitectura)

Esta carpeta contiene archivos Markdown (`.md`) que documentan la arquitectura, lógica y manejo de estado de cada módulo del sistema.
El propósito es que la IA pueda leer estos archivos para comprender el contexto de un módulo sin tener que leer de nuevo todo el código fuente, ahorrando así una gran cantidad de tokens durante el desarrollo y mantenimiento.

## Estructura sugerida para cada módulo:
- Propósito general
- Archivos clave y su responsabilidad
- Lógica principal y flujo de datos
- Manejo del estado
- Dependencias
- Interfaces de datos importantes
- Notas y gotchas (advertencias)
